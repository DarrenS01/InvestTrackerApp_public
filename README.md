# Investment Tracker: published versions

This repository holds the update packages that the Investment Tracker program's **Update app** page reads.
It is filled in automatically by the Release workflow; there is nothing to download here by hand.

- `index.json` lists every published version, with what changed and a checksum for each download.
- The program file (`InvestTracker.exe`) and the source zip of each version are attached to the matching **Release**.
